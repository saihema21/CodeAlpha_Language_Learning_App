# 🌍 LinguaFlow – Language Learning App

LinguaFlow is an interactive multilingual language learning web application built with Python and Streamlit. The application helps users learn vocabulary, practice grammar, review flashcards, improve pronunciation, take quizzes, and track their daily learning progress through a simple and engaging interface.

This project was developed as **Project 3 of the CodeAlpha App Development Internship**.

## ✨ Features

- 🌐 **Multilingual Learning** – Learn Spanish, French, German, and Japanese.
- 📚 **Vocabulary Learning** – Learn words with translations and pronunciation guidance.
- 🃏 **Interactive Flashcards** – Use Previous, Next, and Show Answer controls.
- 📖 **Grammar Practice** – Learn grammar concepts through simple examples.
- 🧠 **Vocabulary Quiz** – Practice with multiple-choice questions and track scores.
- 🎯 **Daily Learning Goals** – Track daily learning progress and completed words.
- 📊 **Progress Tracking** – Visualize learning progress and quiz performance.
- 💡 **Learning Tips** – Receive useful suggestions for improving language-learning habits.
- 🎨 **Clean UI** – Simple, interactive, and beginner-friendly Streamlit interface.

⚙️ Installation & Setup
1. Clone the Repository
git clone https://github.com/YOUR_USERNAME/CodeAlpha_Language_Learning_App.git
2. Navigate to the Project
cd CodeAlpha_Language_Learning_App
3. Create a Virtual Environment
python -m venv .venv
4. Activate the Virtual Environment

For Windows PowerShell:

.venv\Scripts\Activate.ps1
5. Install Dependencies
python -m pip install -r requirements.txt
6. Run the Application
streamlit run app.py

The application will open in your web browser.
